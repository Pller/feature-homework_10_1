# Банковский виджет операций

Проект для обработки и анализа банковских операций клиента.

## О проекте

Банковский виджет операций предоставляет инструменты для:
- Фильтрации банковских операций по статусу
- Сортировки операций по дате
- Обработки и анализа финансовых данных
